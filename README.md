# Mothership RPG - Compendios en Español

Este es un módulo independiente de localización al español para los compendios y bases de datos del sistema de juego **Mothership** en Foundry VTT. Utiliza el módulo **Babele** para inyectar las traducciones en memoria de forma limpia y automatizada.

## 📊 Estado de la Traducción

Puedes ver y colaborar con el progreso del proyecto directamente en nuestra plataforma de Crowdin:

[![Crowdin](https://crowdin.net)](https://crowdin.com)

## 🛠️ Créditos y Reconocimientos

Este módulo de traducción se basa directamente en el increíble trabajo de desarrollo de **Futil**, creador de la implementación no oficial del sistema Mothership para Foundry VTT. 

* Las plantillas de datos y la compatibilidad estructural de este proyecto están vinculadas al repositorio original: [Futil/foundry-mothership](https://github.com/Futil/foundry-mothership).
* Agradecemos profundamente a **Futil** y a toda la comunidad de desarrollo por hacer posible este sistema.
